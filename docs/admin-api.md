# Admin API Reference

Every route under `/admin/`, read from the backend's own route table. The same table drives the MCP tools and resources on `/mcp` and the in-app assistant, so the names below are the names those clients see.

- **Tool**: a mutating route, callable as an MCP tool on `/mcp`.
- **Resource**: a `GET` route, published as an MCP resource and readable through the `read_resource` tool. The in-app assistant calls it by its `get_` tool name, listed in `admin-api.json` next to this page.

Request and response schemas are in the OpenAPI document the backend serves at `/swagger`. Naming rules and exposure controls are covered in [Backend API Tools](./BACKEND_API_TOOLS.md) and [MCP HTTP Server](./MCP_HTTP_SERVER.md).

This page and `docs/public/admin-api.json` are generated by `bun run docs:generate`; `bun run docs:check` fails when they no longer match the routes.
